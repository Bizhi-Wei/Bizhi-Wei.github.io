数据处理与机器学习：深入理解

数据集划分、缺失值处理、标准化与模型训练的核心概念

美妙的数学

  • 通过数学建模预测疾病发生概率
  • 机器学习让电脑自动识别病情
  • 早期AI训练 = 机器学习

3. 数据集划分

划分比例

数据集 占比 用途
训练集 80% 训练调试模型
测试集 20% 测试模型性能

关键原则：避免数据泄漏

⚠️ 不能按patient-id简单划分

问题：患者A第一次住院在训练集，第二次在测试集，模型已知患者A部分信息，导致拟合效率偏高。

解决方案：使用patient-grouped split

地标时间点的数据处理

  • 0h、6h、12h三个地标需确保同一Patient Assignment
  • 6h、12h需排除已发生AKI的患者
  • 可能导致略有不同的Assignment，需在文章中说明

缺失值处理策略

连续数据（身高、年龄等）

使用中位数填补

为什么不用均值？

  • 均值易受极端值影响
  • 中位数更稳健
  • 可取Maximum和Minimum作为参考

添加二元特征标记缺失

例：lactate缺失
新建 lactate_miss = 0
让模型学习"这个位置本身就是缺失的"
缺失原因太多，模型需要知道这一点

分类变量（如性别）

  • 使用众数填补
  • 关键：众数从训练集取值，不能从整个数据库取

⚠️ 重要原则

  • 填充数据是"生成的"，不如原始数据
  • 数据造假可得到优秀模型，但不允许
  • 缺失本身就有含义，需添加二元特征
  • 如有因素（家庭经济、性价比等）可建立模型

标准化

公式

标准化值 = (原始值 - 训练集均值) / 训练集标准差

示例

训练集：年龄均值65岁，标准差10岁
患者：75岁
计算：z = (75 - 65) / 10 = 1
表示比训练集平均年龄高1个标准差

作用

  • 放大特征，便于机器学习
  • 用于Logistic Regression

4. 模型训练与内部验证

Dynamic Landmark构建

构建三个时间点：0h、6h、24h

避免数据泄漏（Data Leakage）

⚠️ 核心原则

  • 6h模型：排除0-6h已发生AKI的患者
  • 24h模型：排除0-24h已发生AKI的患者
  • 不能用病人已发生AKI之后的数据去"预测"AKI

数据划分

使用 80:20 patient-grouped split

四种模型

1. Logistic Regression（逻辑回归）

传统线性基线模型
  • 最经典的二分类算法
  • 输出概率值（0-1之间）
  • 可解释性强，系数直接反映特征重要性
  • 作为基线模型，与其他复杂模型对比

2. Random Forest（随机森林）

集成学习 - Bagging
  • 由多棵决策树组成
  • Bagging思想：每棵树用随机抽样的数据训练
  • 特征随机选择：每棵树只用部分特征
  • 优点：
    • 不容易过拟合
    • 能处理非线性关系
    • 可输出特征重要性排序
  • 缺点：模型较大，预测速度相对较慢

3. XGBoost

集成学习 - Boosting
  • Boosting思想：每棵树纠正前一棵树的错误
  • 梯度提升框架的高效实现
  • 核心特点：
    • 正则化项防止过拟合
    • 自动处理缺失值
    • 支持并行计算
  • 优势：竞赛常胜算法，性能强大
  • 注意：需要仔细调参，否则容易过拟合

4. LightGBM

集成学习 - Boosting
  • 微软开发的梯度提升框架
  • 核心创新：
    • Leaf-wise生长策略（而非Level-wise）
    • 直方图算法加速
    • 支持类别特征直接输入
  • 优势：
    • 训练速度极快
    • 内存占用低
    • 适合大规模数据
  • 与XGBoost对比：速度更快，但可能需要更多调参

内部验证：五折交叉验证（5-Fold Cross-Validation）

什么是交叉验证？

将训练集分成K份，每次用K-1份训练，1份验证，重复K次，取平均性能。

■ 验证集    ■ 训练集

为什么用五折交叉验证？

  • 充分利用数据：每个样本都被用于验证一次
  • 更可靠的性能评估：减少单次划分的随机性
  • 防止过拟合：在训练过程中持续验证

流程

  1. 将训练集随机分成5份
  2. 第1轮：用第2-5份训练，第1份验证
  3. 第2轮：用第1、3-5份训练，第2份验证
  4. ...重复5次
  5. 取5次验证结果的平均值作为模型性能

超参数调优（Hyperparameter Tuning）

什么是超参数？

模型训练前需要设定的参数，不是通过训练学到的。

各模型的超参数

模型 主要超参数
Logistic Regression C（正则化强度）、penalty（正则化类型）
Random Forest n_estimators（树的数量）、max_depth（最大深度）、min_samples_split
XGBoost learning_rate、n_estimators、max_depth、subsample
LightGBM num_leaves、learning_rate、n_estimators、feature_fraction

调优方法

网格搜索（Grid Search）

  • 遍历所有参数组合
  • 优点：找到最优解
  • 缺点：计算量大，耗时长

随机搜索（Random Search）

  • 随机采样参数组合
  • 优点：更快，效果接近网格搜索
  • 缺点：可能错过最优解

贝叶斯优化（Bayesian Optimization）

  • 基于历史结果智能选择下一组参数
  • 优点：效率最高
  • 缺点：实现复杂

调优流程

  1. 定义参数搜索空间
  2. 选择调优方法（如Grid Search）
  3. 使用五折交叉验证评估每组参数
  4. 选择平均性能最好的参数组合
  5. 用最优参数在全训练集上重新训练

⚠️ 注意事项

  • 调参必须在训练集上进行，不能用测试集
  • 交叉验证的结果是模型性能的无偏估计
  • 最终模型用最优参数在全训练集上训练
  • 测试集只在最后评估时使用一次

核心原则

预测模型最怕的就是：用未来信息预测过去事件。
